# COS 与人像专业合成与溶图指南（PhotoCraft 版）

面向 COS 正片场景合成、跨背景溶图、水面倒影置换与光效氛围整合。核心目标：**彻底消灭“人物像贴纸 P 在背景上”的割裂感，让透视、边缘、黑白位、三层阴影、光影包裹、物理景深与传感器颗粒长在同一张底片里。**

> **前置硬门禁（Beauty-First Gate）**：开合之前必须先完成阶段一人物底图（`01_beauty_base.png` + `.pcraft`），确保骨相液化、肤色统一与眼唇细节已过 `1:1` 验收。当前工作流以 **LightCraft + PhotoCraft + Core 侧车（`BiRefNet_lite` / `uniface` / `MediaPipe` / `LaMa` / `Real-ESRGAN`）+ 内置图片模型按需生成场景/前景/特效素材** 为主力，所有素材最终回到 PhotoCraft 做分层精合与 4K 锁罩封装。

---

## 一、物理三对齐（合成前先判生死：透视 · 焦段 · 光向）

调色救不了透视与光向的根本矛盾。置入背景与主体后，先核对以下三项：

1. **视平线（Horizon Line）对齐**：
   - 先找背景的视平线（地平线、建筑消失线交汇高度或水面远界）。
   - 背景中**高度等于摄影师机位的位置，必然落在人物身上同一个高度**（平拍人像时，站姿人物的眼/胸等高点应落在背景视平线上；严禁把平拍半身直接放大塞进高空俯拍背景）。
2. **焦段与畸变匹配**：
   - 广角（≤28mm）空间透视强烈、近大远小明显；中长焦（85mm–135mm）背景压缩感强、轮廓平直。主体和背景焦段冲突时，优先更换素材或对局部建筑/道具做轻量透视校正。
3. **主光方向与软硬质预判**：
   - 明确背景主光源方位（左前/右后/顶光/漫射阴天）与光质（硬太阳光出锐影，大阴天或雾景出宽柔漫影），确保人物主受光侧与背景主光一致；不匹配的背景直接换底或用内置图片模型重绘适配光向。

**PhotoCraft 常用命令**：
- 置入与比例定位：`doc_place`、`edit.transform`
- 建筑/地面/倒影面四点透视对齐：`edit.perspectiveWarp`（`planes: [{ src: [[x,y]×4], dst: [[x,y]×4] }]`）
- 局部姿态或衣摆顺应地面：`edit.puppetWarp`、`edit.transform.warp`
- 镜头畸变对齐：`filter.lensCorrection`

## 二、发丝级精抠与边缘去污（消灭白边、黑边与硬纸片感）

1. **高精度前景 Alpha 提取与按画风选合发路径**：
   - 使用 `retouch-ai.py matte --model birefnet-lite` 提取高净度发丝与薄纱蒙版，配合默认 `SegFormer-B2 Clothes` 18 类 `body-parse --refine-with-matte` 拆出头发/上衣/裙装/鞋袜/腿臂/受保护主体。
   - **接发与遮挡铁律（`retouch-ai.py hair-comp`）**：写实人像/实拍风 COS 默认 `--mode real-first` 保留 100% 原生 4K 真发，仅去夹缝死白背景、半透明杂边与温和回收内侧逆光雾（禁止用低清生图 `realesrgan 4x` 糊发或硬编码 `PIL` 线条覆写全头）；确需局部飘发延展时用 `hybrid-flow`，手臂/面部遮挡**只能紧贴真实轮廓 `0px` 外扩（`0.8px` 抗锯齿）**，绝不留出 5–18px 扩边沟壑把头发切出锯齿断口。
   - **必查死角**：暗部皮肤轮廓、手臂与腰部间隙、半透明头饰（龙角、耳鳍、轻纱、细金属链）最易被算法误抠成孔洞或硬边。
2. **双底色 `1:1` 审边法**：
   - 在主体下方临时放一层纯黑实色层与一层纯白实色层，轮流开关在 `1:1` 下扫视发丝与肩袖外缘，任何残留白边、黑边、灰边都会立刻现形。
3. **去污优先于粗暴缩边（严禁硬削蒙版）**：
   - 大数值收缩选区（负 `shiftEdge`）会把蓬松细发丝直接削成“塑料硬壳”。
   - 正确做法：先用 PhotoCraft 原生边缘净色命令清理半透明边缘残留的背景杂色，再用低流量柔边画笔在蒙版上精修：
     - `layer.matting.colorDecontaminate`（`amount`, `radius`）：就近采样内侧主体色替换边缘溢色（注意比对现场真实彩色轮廓光，别把有益的紫/青边光一并洗掉）；
     - `layer.matting.defringe`（`width: 1~2`）：清理 1–2px 轻微杂边；
     - `layer.matting.removeBlackMatte` / `layer.matting.removeWhiteMatte`：针对纯黑/纯白棚拍底残留半透明黑灰边或白雾边；
     - 若从深暗底抠出转到中浅底，对半透明发丝边缘做数学反混除黑：`FG = (I - (1 - alpha) * BG_old) / alpha`。

## 三、4 张 X 光诊断检查层（`CHECK LAYERS` 组）与三要素溶图

人眼极易被相邻色块欺骗（同时对比效应）。在图层树最顶部建一个名为 **`CHECK LAYERS`** 的临时文件夹，**只用于诊断，交付导出前务必关闭或删除**（在底层做仿制/涂抹时确认取样范围不受顶部检查层干扰）。

### 3.1 四张核心检查层建法（PhotoCraft 原生实现）

| 检查层 | PhotoCraft 精确建法 | 诊断目标（看什么） |
| :--- | :--- | :--- |
| **1. 明度 / 黑白检查层**（Luminosity Check） | `layer.newFillLayer.solidColor` 填 **50% 中灰（`#808080`）**，混合模式设为 **`color`**（或 `hueSaturation` 饱和度 `-100`） | 剥离全部色彩，只核对**人物与背景的亮度、反差、黑位深浅、白位滚降与主光方向**是否一致。**黑白关系对不上，彩色怎么调都假。** |
| **2. 色偏检查层**（Hue / Cast Check） | `layer.newFillLayer.solidColor` 填 **50% 中灰（`#808080`）**，混合模式设为 **`luminosity`**（若色偏太微弱，可在其下方临时加一层 `hueSaturation` 拉高饱和度 `+60..+80`） | 剥离明暗起伏，放大暴露主体与环境之间隐藏的**冷暖色偏、肤色发绿/发洋红、边缘杂色光晕**。 |
| **3. 饱和度地图检查层**（Saturation Map Check） | `layer.newAdjustmentLayer.selectiveColor`（绝对模式）：红、黄、绿、青、蓝、洋红的黑色滑块全拉到 **`+100%`**；白、中性、黑色的黑色滑块全拉到 **`-100%`** | 把整张图转成纯饱和度灰度图（越亮=越饱和）。一眼看出人物衣服/皮肤是不是比远景/雾景“艳得刺眼像贴纸”。 |
| **4. 波浪曲线 X 光检查层**（Solarization Curve Check） | `layer.newAdjustmentLayer.curves` 折线波浪点位：`[(0,255), (43,0), (85,255), (128,0), (170,255), (213,0), (255,255)]`（可切换 `luminosity` 混合模式） | 把平滑明暗拉成多段极高反差条纹，像 X 光一样照出**暗部接缝、抠图残留脏边、修补印记与背景雾气断层**。 |

### 3.2 黑位、白位与三要素对齐步骤（全部剪贴蒙版挂载到主体）

在人物主体上方依次建立调整层并执行 **`layer.createClippingMask`**（仅作用于人物，不污染背景）：

1. **黑位（Black Point）与高光滚降对齐（最关键！）**：
   - 现实空气中存在水汽与微粒，**背景越远黑位越浅（常浮在 RGB 15–30 且偏冷青/灰蓝）**。若抠入的人物暗部是死黑 `RGB(0,0,0)`，立刻像挖了个黑洞。
   - 用 `document.sampleColor` / `view.colorSamplers.add` 测背景同景深最暗处数值，在剪贴 `curves` 中把输入 `0` 对应的输出端点向上抬到匹配黑位，并在 R/G/B 通道微调暗部色温；同步核对高光端点是否与背景亮部一致（防止主体高光死白过冲而背景灰柔）。
2. **环境平均色参考与匹配**：
   - 可临时复制背景层跑 `filter.blur.average` 拿到整个环境的平均色彩基准，或轻量使用 `image.adjustments.matchColor`（必须高 `fade` 或压低不透明度，仅作氛围参考底，严禁直接覆盖把肤色染成泥）。
3. **分通道曲线 + 局部色平衡**：
   - 在 **1 号黑白检查层** 下用剪贴 `curves` / `levels` 拉齐人物与背景反差；
   - 在 **2 号色偏检查层** 下用剪贴 `colorBalance`（分开调阴影/中间调/高光冷暖）或 `curves` 分通道对齐环境色温；
   - 在 **3 号饱和度检查层** 下用剪贴 `hueSaturation` 收敛刺眼高饱和区，同时通过蒙版保住眼瞳与唇彩的自然通透。

## 四、物理光影整合（三层阴影 · 倒影置换 · 反曲线塑光 · 环境光包裹）

### 4.1 三层阴影体系（让人物真正“踩/靠”在场景里）

> **边界铁律**：只有人物与地面、水面、墙面、阶梯等物理支撑面存在接触关系时，才绘制接地阴影；**半身棚拍/悬空半身肖像严禁在底部硬画假落地影子**。

1. **第一层：接触影（Contact Shadow / 最深最实）**
   - 在主体下方建空图层，混合模式 **`multiply`**。
   - 吸取背景接触面最深暗色（带环境冷暖，忌纯黑 `0,0,0`），用小号柔边画笔紧贴鞋底、裙摆落地边缘、手指握持道具缝隙画出极窄、最深的闭合接触暗影，立刻消除“脚底悬浮”。
2. **第二层：环境光遮蔽（Ambient Occlusion, AO / 宽柔底暗）**
   - 在接触影下方再建一层 **`multiply`**，用更大号、低流量柔边画笔在人物底部周围扫出宽柔的漫反射暗区（光线被主体自身遮挡而变暗的过渡），稳住体量落地感。
3. **第三层：方向投影（Cast Shadow / 近实远虚）**
   - 复制主体剪影并按主光方向填暗环境色、垂直/斜切透视压扁（`edit.transform` / `edit.perspectiveWarp`）；
   - **近实远虚**：使用 **`filter.blurGallery.fieldBlur`**（多点控制由近到远渐增模糊）或 `filter.blurGallery.irisBlur` / 渐变蒙版高斯模糊，让影子紧贴脚边清晰、离人物越远越虚散变淡。

### 4.2 水面 / 湿地 / 镜面倒影与置换波纹（`filter.distort.displace`）

1. 复制主体垂直翻转贴合水面交界线，用 `edit.transform` / `edit.perspectiveWarp` 对齐水面透视，建渐变蒙版让倒影越远越淡，并压低整体明度与饱和度。
2. **制作置换贴图（Displacement Map）**：复制水波纹背景去色 → 用 `curves` 大幅拉开明暗波浪反差 → 另存为置换贴图文件。
3. **按波纹扭曲倒影与投影**：选中转为智能对象的倒影/投影层，运行 **`filter.distort.displace`**（`horizontal`、`vertical` 从 `5~15` 起步试调，`mapPath` 指向置换贴图），让倒影真正随水波起伏断裂；交界处轻补微弱水波反光与湿润水圈。

### 4.3 反曲线打光法（Inverse Curves Light Painting —— 保留真实质感）

直接拿实色画笔在脸上/衣服上刷亮光很容易盖掉皮肤纹理和布纹。写实合成优先用**反曲线法**：
1. 在主体上方建一个 **`layer.newAdjustmentLayer.curves`** 并剪贴到主体，大幅提亮中间调/高光并向光源色偏移（如冷青月光或暖金夕照）。
2. 执行 **`layer.layerMask.hideAll`** 把蒙版反相成全黑（隐藏全部效果）。
3. 用低流量白色柔边笔在蒙版上顺着受光骨相转折与轮廓边缘轻扫出高光。
4. 配合 **`layer.layerStyle.blendingOptions`** 的 **`blendIf`**（如 `underlying: [0, 45, 255, 255]` 拆分黑滑块），让提亮高光自然退让出极深阴影缝隙、精准咬在亮部纹理上。

### 4.4 环境光包裹（Light Wrap）、底面反光与轮廓光（Rim Light）

| 光效类型 | 物理来源 | PhotoCraft 非破坏做法 |
| :--- | :--- | :--- |
| **环境光包裹（Light Wrap）** | 亮背景光绕过主体边缘产生大气漫射溢出 | 复制背景置于主体上方并 `layer.createClippingMask` → 大半径 `filter.blur.gaussianBlur` 柔化 → 混合模式设为 **`screen`**（亮景）或 **`softLight`**（暗景），不透明度压在 **`10%–30%`**，配合边缘窄蒙版与 `blendIf` 仅包裹主体外轮廓。 |
| **底面反光（Bounce Light）** | 水面/雪地/亮石板向上漫反射 | 剪贴反曲线或低不透明度 `softLight` / `screen` 层，吸取地面亮色轻扫衣摆下沿、手背与下颌底面。 |
| **逆光轮廓光（Rim Light）** | 主/背光源勾出锐利边缘亮线 | 先用反曲线打底层受光，外缘发丝/空气边再新建像素层设为 `screen` 或 `linearDodge`（调低 **`fillOpacity`**）沿受光边缘轻勾细锐边光；需要整体定向光铺底时可用 `filter.render.relight` / `filter.render.lightingEffects` 辅助参考。 |

### 4.5 极简 Blender 3D 白模 + 内置生图模型双轮精绘与下半身接地 SOP

上半身常有飘发、丝带和景深空气雾做自然遮挡缓冲，但**下半身（裙摆、双腿、袜口、鞋底与地面交界）直接贴在最亮的地上，是整张合成最容易露怯的地方**。针对该瓶颈按以下三步分工执行：

1. **Blender 只做极简 3D 白模与人物立牌 `Shadow Catcher`（5 分钟定死物理规律）**：
   - 不做高耗时的细枝末节建模和材质雕刻，只输出 4 项硬约束：极简白模透视骨架、16-bit Z 深度图（给 PhotoCraft `lensBlur` 用）、太阳光导板，以及用 `scripts\blender-shadow-catcher.py` 将 `02_subject_cutout.png` 按站立鞋跟/前掌点立进 3D 地面渲染出的**同光向真投影层（`Multiply`）**与**地板微倒影层**；
   - 若原图场照本身就在脚下拍出了清晰同向太阳投影，也可按 PiXimperfect Real Shadows 思路直接提取原片真实脚影作为叠加参照。
2. **高分辨率实拍背景（内置分块精绘 或 用户协同抽卡）与 Apache-2.0 PhotoBlaze-PIH ONNX 溶图调和**：
   - **两条合规高分路径（均须满足 `linear_ratio >= 0.6`，严禁低清 `<=1K` 图盲目 `realesrgan 4x` 直接充当 4K 背景）**：
     - **A. 本机/自动分块路线**：走 **`retouch-ai.py tile-split` → 2×2 重叠高清重绘 / `tile-refine` → `tile-stitch`（低频锁光影 + 亚像素对齐）**；
     - **B. Blender 白模协同抽卡路线（推荐）**：将 `01_blender_4k_beauty.png`（定死 85mm 透视、视平线与左→右日光向）交给用户，在外部高清图模（如 **Seedream 5.5** 等，直出短边 `>= 1440px` 真机实拍空镜，严禁加人物与前景大特效）按审美抽卡，再比例缩放回 4K、按新地面实测亮暗阴影配比校准 Blender 投影，所有特效留到 PhotoCraft 内分层穿插。
   - 溶图阶段优先运行 **`retouch-ai.py harmonize --garment-dark-mask <完整深色保护罩>`**（Apache-2.0 `PhotoBlaze-PIH` ONNX CUDA 32 点调和曲线 + 空间光照增益 + 肤色与**包含后踢鞋/黑袜在内的完整黑衣防回灰保护** + 双半径 `Light Wrap` + 颗粒匹配层），再用 PhotoCraft 反曲线与三层阴影微调收束。
   - 对独立 `01_beauty_base` 中的服饰与下肢务必依次走 **`retouch-ai.py garment-retouch --out-dark-mask`**（仅在 CIE Lab 明度 `L*` 去眩光并做纯半透 `alpha` 去白边）与 **`retouch-ai.py skin-unify`**（以手臂晴光肤色统一褪色膝盖、并叠加黑裙与上方交叠腿物理遮挡影）；**墙面/天空方向性 `Screen` 反弹光层必须排除已压暗的下肢膝盖阴影区**，防止把刚立住的裙下遮挡重新抬亮冲灰。
   - 对实拍发丝增加飘逸毛流感时，跑 **`hair-comp --mode real-first --groom`** 与 **`hair-paint`**，按 **后景柔流层（位于主体与黑腰带背面）→ 主体人物组 → 前景极细单丝/Add 飞丝组** 非破坏装配，避免腰带被粗暴截断或前景出现扁平带状笔触。
3. **语义分区与零破洞/零重影铁律（严禁用全局色差或坐标硬切充当蒙版）**：
   - **禁止**拿 `256×256` 粗糙语义蒙版（如 `MediaPipe`）配合硬编码坐标边界（如 `x >= 980`）或全局像素暖色差阈值（`R-B > 18`）区分衣物与皮肤——发丝暖反光会把裙腰误判成皮肤而跳过压暗，造成同一件衣服断成灰棕与纯黑两截；
   - **正确做法**：先跑默认 `SegFormer-B2 Clothes` 18 类 `body-parse` + 引导滤波，先严格隔离 `mask_skirt_dress`、`mask_shoes`、`mask_legs`、`mask_upper_clothes`，仅在 `mask_legs` 内部才允许再用像素色度精细区分裸露膝盖与黑灰袜口；
   - **零破洞不变量**：任何修剪旧假发/旧轮廓的 `trim_mask` 必须强制执行 `trim_mask = max(trim_mask, mask_protected_body)`，绝对禁止亮度过滤或孤立抹除框误穿衣裙与躯干实像素；
   - **刘海防双层重影铁律**：换新刘海时严禁在眉眼或刘海发梢腰部硬挖大半径羽化保护圈（会在额眉交界削出半透明双层重影和眉上白弧）；核心脸 Lock 仅限**刘海尖下方**的眼睛/鼻/唇，新刘海与眉间额肤过渡保持 `1.0` 不透明完整盖住旧刘海，外侧颧颊与飘带隙的旧杂发尾则按 `old_hair - new_hair_silhouette - mask_protected_body` 干净裁除。
4. **教程吸收补充三条硬防线（PTC / PHLEARN / PiXimperfect 实测落地）**：
   - **PTC `Blend If` 黑衣防发灰保护**：所有 `Screen` / `Linear Dodge` 边缘光包裹（`Light Wrap`）必须拆分 `underlying` 黑滑块（如 `[75, 150, 255, 255]`），让光包在深黑衣物上自动退让为零，杜绝黑裙/黑鞋被冲出“白蒙蒙灰雾”；同时低区粒子/斑驳阳光点光严禁扫过深黑裙摆。
   - **PHLEARN 明度黑场去眩光法**：原片暗部（如左裙摆、后踢鞋）若被镜头逆光眩光冲灰发白，须按 **Luminosity（保色相压缩明度输入黑场）** 对齐同件衣物未眩光侧，切忌再叠白色 `Screen` 雾层掩盖。
   - **PiXimperfect 原片真影提取法（保护离地脚跟空隙）**：遇到踮脚/旋转/脚跟微微离地的动态站姿，先核查原图地面是否拍出了清晰实拍投影——通过高对比度通道提取原片真实地影（保留离地脚跟与投影之间的 sunlit 空隙，只在真正踩实的前掌绘制紧贴接触影），以 `Multiply` 校准到新场景栏杆实影的 RGB 比率后延展融合，空间立体感远胜盲目涂黑整个鞋底。

## 五、空间纵深、空气透视与物理景深

1. **前 / 中 / 后三层空间结构（真·3D 大光圈实景前景暗框铁律）**：
   - **前景遮挡**（近景铁艺拱肋、花瓣枝叶、折射晶体光斑）→ **中景焦点主体**（全图最高清晰度与微反差）→ **远景背景**。
   - **实证教训**：仅靠画一层微弱半透明黑角渐晕（Vignette）在人眼观感里依然等于“只加了个滤镜，没有真正的前景”。当人物下方或边缘在构图上被迫裁切时，必须使用 **`fg-vfx-3d`（Blender Cycles `f/1.18–f/1.6` 物理大光圈景深）** 渲染带真实背光边缘与色彩的实景前景道具，将其温柔咬合在人物边角与底缘两侧，才能一秒立出“人物被前后实景包裹夹在空间里”的摄影景深。
2. **空气透视（Depth Haze）**：
   - 在主体与远景之间夹一层极薄环境色柔雾（`screen` 或低不透明度 `normal`），让远景黑位上浮、对比度与饱和度低于前景主体。
3. **物理景深模糊**：
   - 使用 **`filter.blur.lensBlur`**（支持 `depthMap: "layerMask" | "channel"`、`focalDistance`、`shape: "hexagon" | "octagon"` 及高光散景 `brightness` / `threshold`）或 **`filter.blurGallery.tiltShift`** / **`fieldBlur`** 模拟真实大光圈渐进虚化。
   - **一致性铁律**：人物脚下所踩地面的清晰度必须与人物脚部基本一致；严禁背景已经虚化成奶油，人物全身边缘却刀切般锐利（或背景很实而主体发糊）。

## 六、特效与发光物理（Special 8 `fillOpacity` 法则 + 前后遮挡 + 溢光染色）

1. **前后穿插遮挡与能量守恒法则（主次分明，严禁喧宾夺主）**：
   - 光环、粒子、丝带必须拆成“主体后层”与“主体前层”穿插，且 **`vfx-overlay --placement auto-split` 必须遵守严格能量守恒（`a_behind + a_front <= alpha`）**——绝不可在背景区同时保留全量后景与大半前景后再额外叠第三层 `Linear Dodge (Add)` 或把大片粒子云喂进全局光晕，否则极易在亮景里糊出刺眼白雾团，彻底吞掉钢琴/建筑等重要陪体与人物重心；
   - 高密度星尘类黑底 AI 特效层建议调大 **`--density-gamma 1.65~2.0`** 与 **`--haze-suppress 0.65~0.80`**，只保留通透细碎的微光星点作空气氛围衬托。
2. **顺姿因果互动光带（`fg-vfx-3d`）**：
   - 真正有电影联动感的特效不是满屏乱撒贴片，而是**与人物姿态/手持道具直接发生因果联系的流光路径**（例如从手持话筒/法器出发 → 绕过双肩后侧发丝背面 → 穿到身前裙摆前侧 → 渐隐汇向场景中的钢琴/光源），并在主光同侧及光带擦过的人物手臂/发梢/衣褶表面用 2.5D 法线调制的 `Screen` 局部实光反射层（`vfx_wrap_causal_spill_screen`）把光实打实“照”在人物身上。
3. **Special 8 混合模式的 `fillOpacity` 法则（防发光死白爆掉）**：
   - 在 `Linear Dodge (Add)`、`Color Dodge` 等 8 个特殊混合模式中，降低普通 `opacity` 容易发灰发闷；通过 **`layer.layerStyle.blendingOptions`** 降低 **`fillOpacity`**（配合 `transparencyShapesLayer: false`）会直接缩放发光数学叠加强度，**既压住中心不过曝成死白块，又能保留高饱和迷人色晕**。
   - 配合 **`layer.layerStyle.outerGlow` / `innerGlow`** 时，把 `fillOpacity` 设为 `0` 可单独保留纯程序光晕。
4. **反向溢光染色（Spill Light —— 决定特效真伪的分水岭）**：
   - 发光武器、手心法阵、萤火或水波光效**一定会照亮邻近物体**。必须在人物手掌、衣袖、胸前发丝与脸颊受光面建立剪贴层（反曲线或低 `fillOpacity` 的 `linearDodge`），用对应光色补足局部溢光与高光反射。

## 七、VFX 合成树层序与传感器收束（“胶水层”）

### 7.1 标准自底向上图层树顺序

1. **背景底片**（已完成透视与镜头畸变对齐）
2. **远景空气雾 / 背景物理景深**（`lensBlur` / `fieldBlur`）
3. **三层阴影与水面置换倒影**（接触影 → AO → 渐虚方向投影 → `displace` 倒影）
4. **特效后层 & 主体后飘发组**（主体背后光环/水雾/粒子 + `02b_HAIR_PAINT_BEHIND_4K` 让背后发丝自然绕出肩颈与腰带）
5. **主体人物组**（`01_beauty_base` 精抠去污 → `garment-retouch --out-dark-mask` → `skin-unify` → `harmonize --garment-dark-mask` 剪贴调色 → 上身墙面/地面反光（排除下肢阴影）→ `Light Wrap` / `Rim Light`）
6. **主体前飘发组 & 特效前层 & 前景虚化**（`03b_HAIR_PAINT_FRONT_4K` 极细 `Normal` 碎丝与 `Linear Dodge (Add)` 飞丝 + 越过肩袖的前景花瓣与近景散景模糊）
7. **全局统一调色（“色彩胶水”）**：`filter.cameraRaw` / `curves` / `colorLookup` + 轻微压暗四角锁视觉焦点
8. **最顶层传感器颗粒（“像素胶水”）**：
   - 新建 50% 中灰层（`layer.new.layer` 配 `fillNeutral: true`），混合模式设为 **`overlay`** 或 **`softLight`**；
   - 运行 **`filter.noise.addNoise`**（`distribution: "gaussian"`, `monochromatic: true`，少量 `1%~3%` 匹配背景噪点密度）。
   - **顺序铁律**：颗粒永远加在最顶层（绝对不要放在 `lensBlur` 下方被糊成脏斑）；必要时对极锐人工边缘在通道层面补微弱色散（`blendingOptions.channels`）对齐真机镜头质感。

### 7.2 合成收尾与交付验收

1. **关闭/删除 `CHECK LAYERS` 组**；
2. 先运行 `retouch-ai.py mask-audit`（核查零破洞、零半透明双层刘海重影、单件服饰无色调断层，并审阅高亮叠色诊断图），再使用 `doc_render_preview` 看整图大关系，配合 **每处核心接缝独立一张 `<=512px` 的真 `1:1` 切片**（眉眼刘海、发衣交界、服饰黑位、脚底接地）直接视觉验收——严禁只看整图缩略图或把多图缩拼在一起充当 `1:1` 检验；
3. 先 `doc_save` 保存完整可编辑 `.pcraft` / `.psd`，再视交付需要执行 `edit.convertToProfile` 转 `srgb` 导出并重开复核。

## 八、去塑料感与影视级质感硬标准（40 张高水准 COS 合成作品拆解）

通过系统拆解 40 张 3K–4K 实战级影视 COS 合成作品（含水下神殿、古风室内、水墨长卷、雪夜飞剑等题材），总结出防止画面滑向“塑料手办 + 页游海报贴图”的 **5 条反塑料铁律**：

1. **背景必须有“真实物质与建筑肌理”，禁止空泛平滑模糊渐变**：
   - 合格合成背景哪怕在暗夜或水下，也应有**石柱砖缝、木格门窗、珊瑚礁石、瓦片栏杆或桌面器具等可辨识物理肌理**，并保留随景深渐进衰减的微纹理。
   - **避坑**：严禁用低清平滑 AI 图跑 `Real-ESRGAN 4x` 再叠大半径 `lensBlur`（`radius ≥ 12`）把背景磨成橡胶渐变；也不要直接贴大面积半透明发光 CG 神兽/法阵充数。
2. **头发坚持“哑光微纤维 + 深暗沟槽 + 仅边缘极细背光丝”，禁造 PVC 塑料条**：
   - 真人/高阶厚涂发丝内部必须保留**哑光颗粒感与扎实的发束暗部沟槽**，高光只落在迎着背光的最外圈细发丝上。
   - **避坑**：严禁把低分辨率 AI 生成的平滑头发 `4x` 超分后直接贴回 4K 主体，更不可在其上大面积叠加反曲线亮油光，否则必出“白色塑料牙膏条”。
3. **敢于压实人物立体明暗比（4:1–6:1），拒绝扁平亮白贴纸脸**：
   - 当背景主光在侧后方或强逆光时，人物正面皮肤与衣料必须顺应环境**主动压出明确的暗面转折（鼻侧、颧下、下颌底、臂下）与扎实深暗部**，把最亮区域让给背光轮廓或真实局部主光，切忌保留全平光大白脸再把暗部整体抬成灰雾。
4. **色彩走“低饱和影视级冷暖对撞”，禁用全屏高饱和荧光单色**：
   - 即使主基调是冷青/暗蓝，也要压制背景高饱和度并设置**清晰的暖色物理锚点**（如暖灯笼、木质暖影、羊皮卷/金饰微暖），避免背景、空气雾、包边光全染成刺眼的荧光青绿。
5. **特效要有“实体物理粒子与前景框景”，不用模糊发光雾团**：
   - 水流应有折射高光与清晰飞溅水珠，烟雾应带颗粒感与细碎火星，飘雪/飞尘/花瓣应配合**方向性动态模糊（`filter.blur.motionBlur`）**；
   - 在画面四角/边缘布置**暗色或虚化的前景框景物（石柱、屋檐、器物、水花）**，比单纯拉黑角更能立住电影摄影纵深感。

## 九、COS 合成高频翻车诊断速查表

| 翻车症状（一看就很“P”） | 真实物理根因 | PhotoCraft 对应修法 |
| :--- | :--- | :--- |
| **整张图“塑料感/页游海报味”重** | 平滑 AI 背景超分再大模糊 + 高饱和荧光单色 + 低分超分光滑发条叠亮油光 + 正面平光缺暗部 | 改用高材质实景底（`lensBlur` 克制 `4~7`）、人物哑光保肌理收高光、压实暗面 `4:1` 反差、加前景框景与冷暖双锚点 |
| **人物像悬空纸片贴在地上** | 缺接触影与 AO，或投影整圈死黑一样糊 | 补 `multiply` 紧贴缝隙的接触影 + 宽柔 AO + `fieldBlur` 近实远虚方向影 |
| **上半身很融，但下半身/鞋袜/膝盖接地面很违和** | ① 投影方向/硬度没对上场景影向；② 强逆光把膝盖肤色冲成灰白且 `SegFormer` 误标 `mask_pants`/漏检鞋靴，或黑裙/交叠腿下方缺物理遮挡影；③ 鞋袜去白边扩展过深在鞋底画出黑描边，或溶图未保护后踢鞋导致回灰；④ 墙面 `Screen` 反弹光误照亮了下肢阴影区 | `blender-shadow-catcher.py` 对齐地面影向 + `garment-retouch --out-dark-mask`（仅半透 `alpha` 去白边）透传给 `harmonize` + `skin-unify` 对齐手臂肤色并叠裙/腿遮挡影，同时屏蔽下肢区 `Screen` 反弹光 |
| **人物边缘发白/发黑或像剪纸** | 抠图半透明背景残留 + 未做边缘光包裹 | `colorDecontaminate` / `removeBlackMatte` + 10%–25% 柔和 `Light Wrap` |
| **远景发灰发蒙，人物像挖了个黑洞** | 人物黑位 `0,0,0` 与背景空气透视浅黑位脱节 | 打开 1 号黑白检查层，用剪贴 `curves` 抬高人物暗部输出端点对齐背景最暗值 |
| **人很艳很锐，背景很淡很糊** | 饱和度与景深双双失衡 | 用 3 号饱和度地图对饱和度 + 对人物或脚部执行轻量 `lensBlur` 匹配景深 |
| **倒影和纸板一样笔直呆板** | 水面倒影没做波纹折射、没压暗衰减 | 对倒影用高对比水纹灰度图跑 `filter.distort.displace` + 渐变蒙版渐隐 |
| **发光法阵/特效糊成一团白塑料** | 用常规 `opacity` 硬叠且没画周围物体受光 | 改用 `linearDodge` 压低 `fillOpacity` 保留色晕，并在手/衣/脸补对应溢光 |
| **人物高清无噪，背景全是压缩颗粒** | 主体与背景传感器噪点不统一 | 顶层 50% 中灰 `overlay`/`softLight` 加微弱单色高斯 `addNoise` 统一颗粒 |
| **半身人像底部莫名多一团黑影** | 对没有支撑面的悬空半身图硬加了落地阴影 | 删除无根据的落地投影，改用正常肩臂明暗衰减与环境光包裹 |
