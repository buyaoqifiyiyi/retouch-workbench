# 二次元厚涂 COS 方法卡（PhotoCraft 版）

当用户明确要求**二次元厚涂 / 明显塑形与角色感重绘**，或已否决“几乎不变的自然轻修”时启用本参考。核心判断：**厚涂感来自“重新组织脸部明暗大面、明确眼唇妆面层次、将碎亮假发概括成有体积与前后遮挡的发束”，不能靠轻微调色、全脸模糊或几个柔光圆斑凑出来。**

> **前置硬门禁（Beauty-First Gate）**：在执行换背景、AI 重打光或厚涂风格化之前，必须先按 [骨相液化指南](liquify-guide.md) 与 [自然奶油肌精修指南](natural-beauty-guide.md) 完成 **阶段一自然美颜底图（`01_beauty_base.png` + `.pcraft`）** 并通过 1:1 验收（皮肤洁净温润 `Lab b* ≈ 8~13`、全臂连贯无手镯断层、超分鼻孔黑线已清理、零贴纸眼唇）。禁止拿未精修原片直接硬画厚涂或硬抠换背景。

执行原则：
- 按 **① 脸部结构组 → ② 眼唇妆面组 → ③ 示范发束与发丝组（含藏色环境过渡）** 或配合 **方法卡四（AI 辅助厚涂管线）** 分组推进，每组独立可见开关与独立蒙版，避免把变化混成一团无法回退。
- 每做完一组同时核对**适屏整图**（明暗大形、视线重点、大束体积与环境光包裹是否成立）与 **1:1 局部裁切**（五官可读性、眼线/唇缝连续、手部/饰品辨识、发束交叉遮挡）。

## 方法卡一｜脸部结构面重构（去碎亮点，立大面）

### 适用判断
原片闪光灯下常见鼻头红亮、局部反光碎斑、皮肤明暗起伏零碎，导致视觉重心被琐碎反光抢走；参考厚涂图通常皮肤更浅净，鼻梁亮面更集中，同时眼窝、鼻侧、唇下与下颌仍有清晰体积转折。

### 操作顺序与图层结构（由下向上）
1. **建立“脸部结构”图层组**（`layer.new.group`）：组蒙版只显露皮肤区域，先明确避开刘海、眉毛、眼妆、鼻孔与唇缝（可先运行 `retouch-ai.py face-parse` 生成严格与眼眉唇互斥的 `mask_skin.png` 辅助起稿）。可临时在最上方放一个去色观察层（用完关闭/删除）检查纯明度形状。
   - ⚠️ 注意：把重绘层剪贴到整张不透明照片上**不会**自动把绘制限制在皮肤里，必须用皮肤空间蒙版。
2. **`Normal` 大面概括层**：取本脸自然中间肤色，用 `paint.stroke` / `paint.mixerBrush` 局部覆盖零碎反光点与杂斑，整理出连续的额面、面颊与鼻梁受光面。保留五官边界，严禁把整张脸平涂成单一色板。
3. **`Multiply` 结构暗面层**：只补缺失的结构阴影（刘海投影、鼻侧转折、下唇下方、下颌衔接）。原图本来就较深的鼻侧影不要再叠乘黑洞；想减弱的过重旧影，应在前一步 `Normal` 层直接修改色值。
4. **硬软边取舍**：需要干净轮廓的暗形用套索选区或较硬笔刷定形，面颊圆转与下颌向颈部过渡只局部软化边缘。
5. **`Normal` 亮面重绘 + `Screen` 集中高光**：重画受光面，再单独用小范围 `Screen` 层点出集中亮面；鼻梁亮面与鼻头高光分开设计，不要画一条从额头直穿鼻尖的白柱。
6. **独立 `Color` 局部修色**：阴影发脏时，在独立 `Color` 混合模式层补暖/冷偏色或邻近回混；先解决明度结构，再调粉红/玫瑰气色，最后回到彩色对比脸、颈与现场环境色关系。

### 失败迹象（见到即回退/重做）
- 所有阴影全变成柔边粉雾，鼻翼/下颌失去立体转折（结构未建立）。
- 原深影区又叠加 `Multiply` 变黑洞，或鼻梁高光连成生硬白条。
- 整脸变成无差异塑料色板、眼窝被提灰（皮肤蒙版未避开五官边界）。
- 缩略图看起来只是“更亮更白”，明暗形状本身没有改变（仍停留在轻修，未达厚涂目标）。

## 方法卡二｜二次元眼唇妆面层次（立重心，保可读）

### 适用判断
厚涂风格提高肤色洁净度后，眼唇对比需要同步收整，才能让视线先落在眼睛，再落到鼻唇。重点在于整合与提纯现有妆容形状，而非盲目替换眼睛或复制对称睫毛。

### 操作顺序与图层结构
1. **建立“妆面”图层组**：两眼、嘴唇各用独立子层或独立蒙版，方便单独回退一只眼或一段唇线。**严禁直接贴实心色块当眼睛或嘴唇（抗贴纸铁律：`BV1bFeazGE6y` / `BV1S5AczkE2p`）**——一切重绘层须取自原图深浅基准并以半透明层级（`35%–65%`）融入原眼窝与唇床投影。
2. **`Normal` 境界整理 + `Color` 妆色组织**：先在柔和过渡中整理现有眼型、上睑走势、内眼角小面积肉粉提亮与瞳孔中心；用 `Color` 局部组织玫瑰/琉璃/青碧等眼影氛围，外缘必须向肤色柔和消融。
3. **保留上睑压暗与睫毛分组**：用重申的暗色轻轻接实睫毛根与双/内眼皮褶皱暗边；上眼睑向下的自然阴影必须压暗虹膜上部约 `1/3`，切忌把虹膜画成通体均亮的玻璃球贴纸。上睫毛按主光方向分 **3~5 簇渐变主睫毛** 辅以少量细尖飞丝，避免硬边框或机械对称复制。
4. **虹膜与眼神光分层**：虹膜仅下半部受光通透，保留清晰柔和的瞳孔边界；眼神光点随头部透视与主光方向错落安置（主高光 + 极小辅反光），切忌把眼白和虹膜一起提成死白。
5. **嘴唇立体与柔边过渡**：沿原唇珠起伏整理下唇柔润受光面与上唇M字/中缝暗线，外唇缘向人中及嘴角柔和渐隐；绝不涂成高饱和僵硬唇块，也不将唇色外拖污染人中。
6. **联动腮红与局部验收**：将腮红、鼻头暖意与唇色轻轻联系，避免鼻头原有红亮区与新腮红糊成一片。1:1 检查眼线连接、睫毛尖端收细、虹膜上部压影与唇缝连续性。

### 失败迹象
- 眼白与虹膜一起被提成死白、瞳孔边界模糊。
- 眼影绕眼框涂成一圈均等紫黑描边，或左右眼高光/睫毛透视明显机械复制。
- 唇缝被磨掉、嘴角溶化，或只把瞳孔调得极鲜艳却没动明暗形状。

## 方法卡三｜假发成束重绘与补丝（先体积，后飞丝）

### 适用判断
摄影原图假发常在闪光/复杂灯光下呈现大量细碎乱反光、内部毛流杂乱或局部毛躁；参考厚涂画风则概括为宽窄不一、有弯折与前后压叠的大发束，最后辅以少量精细游丝。

### 操作顺序与 PhotoCraft 实现路径
1. **规划流向与前后遮挡**：先梳理头顶发旋 → 两侧刘海 → 贴脸/肩后/胸前长束的前后层序；**必须先画后层发束，再画压在前面的前景发束**。
2. **用大发束盖掉碎亮丝（`Normal` 底形层）**：
   - 先只挑一束侧发或一块刘海做示范验收。
   - 取原图假发中间色，在 `Normal` 层画出边界随毛流弯曲、发梢自然收尖的大束，**有意覆盖其中无规律的碎反光**；严禁画成等宽管状或用半透明薄纱敷在原碎丝上导致碎丝穿帮。
3. **立出“暗侧—主体色—藏色环境过渡—受光转折”**：在独立 `Normal`/`Multiply` 层补每束的暗侧、发根及交叉遮挡接触影——**上方发束压在下方发束时，下方交界处必须有接触暗影**，不能两束同时透亮。**藏色法（`BV1hVgLe1EKG`）**：受青蓝/月白环境光影响时，不在原发色上单一降明度画出脏灰黑，而是在明暗交界与边缘反光区将色相微推向环境冷色（青碧/淡紫）并**适当提高局部饱和度**，再轻揉融入发束，获得通透空气感。
4. **曲率亮带**：用偏浅但保留发色的 `Normal`（必要时小范围 `Screen`）顺发束曲率画主要亮带，亮带要有宽窄差和自然断裂，不可沿边缘画一圈均匀纯白线。
5. **短距局部混色（`paint.mixerBrush` / `paint.smudge`）**：只在该发束层内沿毛流短距离融合色彩，确认采样设置（避免开启 `sampleAllLayers: true` 把皮肤、红衣或背景色拖进头发里）。
6. **大束成立后再补有限细丝（`path.stroke`）**：
   - 整图看大发束体积与遮挡成立后，建最上方细丝 `Normal` 层。
   - 用曲线路径配合 `path.stroke`（`tool: "brush"`、`simulatePressure: true` 模拟双端压感尖细），仅在焦点附近、轮廓转折和发梢添少量毛流丝与飞丝；暗部留白克制，不可靠堆砌大量平行细丝掩盖大束体积失真。
7. **若有新增造型发束**（如参考图多出的跨胸长发）：另建“新增前景发束”独立组，先画完整剪影与衣物/饰品遮挡，再补光影，独立开关验收。

### 失败迹象
- 整图仍是一片毛躁，只多出几条亮线（大束概括未发生）。
- 每束等宽、高光亮度均一、缺少暗侧与交叉接触影（塑料水管 / 漂浮贴纸感）。
- 长距离涂抹产生色条拖尾，或把肤色/衣物颜色串进发区。
- 靠无限加密细丝试图救体积，或发梢齐切缺少自然收尖。

## 方法卡四｜开源 AI 辅助厚涂管线（BiRefNet + IC-Light + Counterfeit + ControlNet Tile）

针对“纯滤镜/几何笔刷难以做出真实环境光包裹、大束绘画感与衣纹融合”的场景，在 **阶段一 `01_beauty_base.png` 验收通过后**，结合本机 6 GB VRAM 隔离生成管线（`retouch-ai.py` + `retouch-gen.py`）与 PhotoCraft 分层拼合执行：

1. **高精度前景抠图（`BiRefNet_lite` · MIT）**：运行 `retouch-ai.py matte --model birefnet-lite` 提取高净度 alpha；对半透明发饰（如龙角、薄纱、耳鳍、细金属链）做软边保护与保留，严禁硬切死白边。
2. **环境光重打光融合（`IC-Light` · Apache-2.0 / OpenRAIL-M）**：基于 `01_beauty_base.png` 跑 `retouch-ai.py relight`（`cfg=2.0`, `left`/`top` 光向对比择优），生成带自然环境背景、轮廓溢出光（light wrap）与柔和投影的底图，并以**低频色彩/光影转移**把背景环境光与边光融回到清透的高清美颜底图上，彻底消除“人物和背景各亮各的”贴纸感。
3. **双通道可控二次元厚涂（`Counterfeit-V3.0_fp16` + `ControlNet-v1-1 Tile`）**：
   - **Pass 1（结构与材质厚涂）**：较低控制或中重绘幅度（`strength ≈ 0.34~0.40`、`control_scale ≈ 0.80~0.88`）作用在**发束、发饰、丝绸服饰褶皱与水雾背景**，让散碎假发丝自然归纳成有笔触感与“藏色”过渡的大束；
   - **Pass 2（高保真面部/手部守护）**：极保守重绘（`strength ≈ 0.20~0.24`、`control_scale ≈ 0.94~0.98`）轻润脸部光影大面与通透虹膜，保留真人五官辨识度与完整手指结构。
4. **PhotoCraft 分层保真回贴（`.pcraft` 可编辑终稿）**：按“隐去原底图 → `01_beauty_base` → `IC-Light` 环境底与氛围光混合层 → 蒙版切入 Pass 1 头发/服饰/龙角厚涂 → 蒙版轻叠 Pass 2 脸部大面 → 从美颜底图/局部修复回高频眼睫饰品细节 → 整体色彩平衡与 1% 单色胶片颗粒”编排，保证全图既具备二次元绘画高级感，又经得起 1:1 五官与质感放大检查。

## 方法卡五｜2.5D COS 板绘厚涂通用流程（抖音高赞实操拆解 + 4K 分层精绘）

结合对高赞 COS 板绘厚涂实战教程（4 分钟无废话实操逐帧与字幕逐条拆解）的完整迁移与西施「游龙清影」4K 实测验收，总结可复用到日常修图与 PhotoCraft 分层的 6 步标准流程（不依赖特定软件笔刷编号）：

1. **前置底盘：先液化定比例 + 先写实向 AI 超分到 4K（严禁错用动漫模型破坏真人材质）**：实拍底图先跑写实向 `Real-ESRGAN`（`realesrgan-x4plus` 配合 `GFPGAN` 清超分黑线）与骨相液化+自然美颜；对偏 2.5D 厚涂的超分升级也**必须继续使用写实模型 `realesrgan-x4plus`**，**严禁对 COS 成片跑 `realesrgan-x4plus-anime` 或在提示词里强调“板绘插画感”**（否则会把服装、金饰、手部、衣领和下颌全勾出平面漫画黑描边，直接毁掉真人 COS 的 3D 质感）。
2. **阶段一：全身肤色统一 + 无描边块面厚涂**：保持真人 3D 皮肤与骨骼立体转折（忌用平面黑边描下颌/手指），柔扫统一头颈、锁骨、肩臂与手部明度；如需从暗底升级明度，对发丝提亮阴影并轻降过重灰青饱和度，对皮肤抬升中间调并轻柔回融 ~25–30% 自然白瓷红润底色，保留 70% 厚涂丝绒大光影。
3. **阶段二：“上深下浅”宝石眼 + 严锁角色原瞳色（防跑色）**：
   - 如重绘阶段误改瞳色（例如西施紫罗兰瞳误变成蓝色），须在真实眼裂与虹膜像素掩码内（严格避开眼白与高光点），将自然 4K 底图的原生瞳色 `Lab (a*, b*)` 与 35% 精细虹膜纤维纹亚像素融回，**保留厚涂原有上睑压影、柔边深锁边与真实睫毛**，只做轻柔下半虹膜透光提纯。
   - 若手动补刻五官细节，严格遵循教程顺序：叠层柔焦双眼皮与眼窝影 → `Linear Dodge (Add)` 高光放顶并压透明度防假 → **淡出三角簇**自然睫毛（忌竖直梳齿） → 感叹号（`!`）鼻光与微扬微笑唇缝，全凭软硬明暗边塑造体块，不加漫画黑边框。
4. **阶段三：拯救僵硬假发的分水岭 —— S 形丝绸发束 + 飘散碎发，并用真实 4K 高频护住服化道**：用顺滑立体的 S 形发束与少量飘散碎发替代实拍硬直化纤反光并带入淡冰青 **藏色**；随后抽取自然 4K 原片的签名高频（`Soft Light` 中灰叠加）回填至**非发丝、非面颊**的真丝裙、金饰莲花、贝壳链、龙角与手指边缘，既保住飘逸厚涂头发，又守住真实 4K 服装材质。
5. **阶段四：暗底换中浅棚拍底色 —— 数学反混去污（Color Decontamination）+ 环境回光包裹（Light Wrap）**：当厚涂稿背景过暗过压抑需换回清透“中浅冷灰蓝影棚调”时：
   - 先用 `BiRefNet_lite` 精抠 Alpha（清掉 < 220px 游离碎渣、轻闭合并护住极细发梢）；
   - 对半透明边缘像素做**背景颜色反混除黑**（`FG = (I - (1-alpha)*BG_old) / alpha`，向内腐蚀缩进采样纯亮内景色并修正外 10px 暗底吞色边缘），彻底斩断发丝/龙角在浅底上的深灰脏边；
   - 合成到带柔和头肩光斑、四角自然压暗与极细单色棚拍颗粒的中浅冷灰蓝渐变背景，再沿主体轮廓内推 `14px` 极轻 `Screen` 环境回光包裹与点睛高光（零 `>=254` 死白溢出）。
6. **阶段五：`1:1` 特写与量化双核**：导出 `.pcraft` / `.psd` 分层终稿与 4K PNG，重点放大看发梢无黑边、无漫画线描、瞳色纯正且双手五指与金饰纹理真 4K 清晰。

## 方法卡六｜PhotoCraft 走势底稿 + 强多模态图模一步厚涂飘发与 4K 锁罩回贴

### 核心分工原则（各司其职）
在保留真人 COS 摄影级皮肤纹理、五官神态与真实服化道（**拒绝对真人“假人化/蜡像感/漫画黑描边”**）的同时做出灵动飘逸的 2.5D 厚涂发丝时，采用 **PhotoCraft 控结构锁前景 + 强多模态图模直接渲染微发丝** 的协同管线：**绝不先过低精度量化模型中转后再二次精修**（否则会继承低精度模型留下的光滑塑胶/CG 高光束感）。

### 五步闭环实操
1. **阶段 0–1（底盘与自然精修门禁）**：写实向 `realesrgan-x4plus` 拉清 4K → 冻区骨相液化 → 清理超分鼻孔黑线与瑕疵 → 统一头颈肩臂通透白瓷肤色，锁住原瞳色与服装/金饰高频细节。
2. **阶段 2（厚涂定妆与氛围锚点）**：先确立脸部柔润立体大面、宝石眼与微光唇妆、棚拍暗灰/水雾氛围及服装光影；该版底图即作为后续重绘发丝的唯一黄金原底（确保五官、饰品、手部与背景基准不再走样）。
3. **阶段 3A（PhotoCraft 语义前景锁罩 + 手绘走势引导底稿）**：
   - 运行 `face-parse`、`matte --model birefnet-lite`、`body-parse --refine-with-matte`（默认 `SegFormer-B2 Clothes` 18 类 + 引导滤波）合成严格前景锁罩，保护面部、紫瞳唇妆、耳饰、头饰、手部、道具及肩臂裙身（强制 `trim_mask = max(trim_mask, mask_protected_body)` 绝不穿孔）；**所有锁罩边缘必须严格卡在刘海尖下方眼鼻唇边界外并顺应轮廓自然收边，严禁用硬直角矩形框切穿发区或用过大的上扩眼区羽化圈切出半透明双层刘海重影**；
   - 在 PhotoCraft 独立引导层用平滑渐细曲线手绘发束体块阴影与左右飘发大走势、胸前垂发走向，输出走向引导底图。
4. **阶段 3B（干净底图 + 走势引导 → 强多模态图模一步直出发丝）**：
   - 将**干净黄金原底**与**PhotoCraft 走势引导图**双图送入强多模态图像编辑模型一步生成柔顺微发丝，保留根根分明的自然毛流、空气刘海与发梢垂坠；
   - **提示词避坑铁律**：严禁写入易诱导生成白色烟雾/棉絮或廉价青色发光抠图边的词汇（如 `smoke / mist / fog / cotton / cyan rim light`）；若使用风格参考图，须先验明无文字水印与无严重色偏；尽量保留刘海发缝锚点，避免大面积擦成空白洞。
5. **阶段 4–5（写实 4K 超分 + 亚像素对齐 + PhotoCraft 前景锁罩封装 + 掩码审计）**：
   - 对选定发丝预览图走写实向 `realesrgan-x4plus` 升回 4K（严禁 `-anime`）；
   - 基于 `fg_lock` 锁定区域执行 `ECC` 亚像素对齐与暗雾外圈 Lab 色温匹配；
   - 严格通过 `(1 - fg_lock)` 只把重绘头发与柔和颈胸接触影回贴至干净黄金原底，用 `old_hair - new_hair_silhouette - mask_protected_body` 清除外缘飘散旧碎发尾，封装为 `.pcraft` / `.psd` 分层工程前先跑 **`retouch-ai.py mask-audit`** 确认零破洞、零双层刘海，再用**独立单张 `<=512px` 真 `1:1` 切片**逐区验收（不拿大拼图缩略图代替 `1:1`）。
