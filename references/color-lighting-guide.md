# COS 与人像调色、光影重塑与同层溶图指南（PhotoCraft 版）

面向室外阳光合成、欧式廊道/庭院正片与二次元 2.5D COS 后期。核心解决两个最致命的“一眼假 / 廉价感”问题：**全图同色系脏土黄发闷**，以及**人物明明抠得很细，却总像贴在背景前面“不在同一个图层里”**。

---

## 一、泥巴黄陷阱：为什么很多合成图“全屏发黄又发脏”

在 `v2` 玫瑰花廊实测（`02_rose_arcade_final_v2.png`）中，定量检测直接抓出了全图发闷的数学根源：

| 指标 | 失败样本（`v2` 脏土黄版） | 商业高透 COS 正片实测参考（Top 12 明亮组） | v3 合格达标线 |
| --- | --- | --- | --- |
| **阴影平均色相 / 饱和度** | **`38° / 42.7%`**（脏茶垢褐） | **冷青蓝/蓝紫 `195°–250°`** 或干净低饱和灰（`2%–15%`） | **冷移 `195°–250°` 或 `sat <= 22%`** |
| **高光平均饱和度 `hi_sat`** | **`20.0%`**（高光泛油黄） | **`1%–7.5%`**（清透微暖纯白 / 香槟白） | **`<= 9%`**（绝不泛蜡黄） |
| **全图平均饱和度 `sat_mean`** | **`37.7%`**（背景 `43.4%`） | **`10%–25%`** | **`14%–26%`** |
| **整体平均亮度 `luma_mean`** | **`113.8`**（灰暗偏沉） | **`125–155`**（空气高调感） | **`128–152`** |

**三大成因**：
1. **暖上加暖的无脑叠加**：原本偏暖的砂岩底图再叠暖金光柱、暖花瓣与全局暖滤镜，导致阴影、中间调、高光全部锁死在 `30°–45°` 高饱和黄褐色带里。
2. **暗部缺少“天空/环境冷漫反射”**：户外阴影面并不受太阳暖光直射，照亮阴影的是**天空冷蓝与地面漫射冷灰**；若阴影饱和度超过 `25%` 还偏黄，观感立刻像“陈年茶渍”。
3. **高光没洗白净**：日光高光一旦饱和度高于 `10%`，画面立刻失去空气通透感，人物奶油肌和浅金发也会被同色系土黄吞没。

## 二、冷暖分色阶与避坑红线

调色必须遵循 **“洗净背景底 → 冷暖分色阶 → 主次护肤色”** 三步顺序，禁止背景还没洗干净就靠全局滤镜硬压：

1. **先把背景“脏黄区”清洗掉（Background Hue Decontamination）**：
   - 定向压低背景 `20°–55°`（橙黄/土褐石材、泥墙）饱和度 `55%–70%`，将其洗成**清雅低饱和冷灰白 / 法式石灰石**；
   - 绿叶/爬藤若发枯黄（`45°–95°`），顺势轻推向通透冷翡翠/青翠（`125°–145°`），同时适度压低饱和避免抢主角；
   - 花朵（如浅粉/奶白玫瑰）与烛火/琉璃暖光点保持独立干净色调，充当极少数精准“暖色锚点”。
2. **冷暖分离（Split-Toning）**：
   - **阴影（Shadows，`luma < 110`）**：主动推向清透的**法式冷板岩蓝 / 微紫灰（`hue 195°–250°`）**，饱和度克制在 `<= 22%`，保证死黑不上浮为脏灰；
   - **高光（Highlights，`luma > 195`）**：拉回干净的**香槟纯白 / 微冷珍珠白（`hi_sat <= 9%`）**；
   - **皮肤/唇色/主花保持温润**：皮肤借助严格蒙版守住 `Lab b* ≈ 7.5–13.0` 的通透奶油感，不被背景冷调带偏成青灰死人脸。
3. **严防色块抢镜**：远景深度墙面、两侧砖缝暗块降低局域反差，让视觉第一眼无条件落在“暖金发 + 瓷白肌 + 纯黑转裙”的主体上。

## 三、把人物真正“放进同一图层”的四大物理支柱

“抠得很干净，但像贴在前面一层”在 `v2` 里也有精确的像素证据：
- 主体背光右臂均亮度高达 **`190.2`**，几乎等同于被太阳直射的地面亮石砖（`192.1`）；
- 主体全局拉普拉斯清晰度高达 **`141.8`**，而同景深背景只有 **`54.7`**（**足足相差 2.6 倍**）；
- 人物边缘过细（仅几像素微光）且缺乏远景空气透视，导致大脑立刻识别出“前后两张底片硬拼”。

### 支柱 1｜同光源方向的真实立体塑光（Directional `4:1` Relighting）
- **先看背景光源方向**：若太阳在左后斜上方（由左柱廊射向右下方地面），人物左侧轮廓、发梢与肩袖顶缘应亮，而**右侧背光手臂、右半边脸颊侧影、裙摆右半幅与背光小腿必须明显压暗，并吃进少量冷蓝空气漫反射**。
- **硬数值准则**：背光面皮肤（例如顺光反面的右侧手臂）的平均亮度必须显著**低于**被太阳直射的石板地面：
  `arm_shade_luma <= stone_sun_luma - 18`（绝不出现背光手臂和太阳晒地一样亮的情况）。
- 若廊柱或栏杆在画面形成明暗条纹光，必须在裙摆/小腿上用柔边 `Soft Light` 或反曲线轻扫出呼应的**条纹光斑与地面反光（Bounce Light）**。

### 支柱 2｜视觉焦点分级锐度匹配（`lapVar` Reconciliation，只保眼睫如刀）
- 把真实镜头里的主体与同焦平面地面放在一起，不可能浑身每一条裙褶毛线都比周围石砖清晰 `2.6` 倍。
- **分级处理**：用**眼眉 + 唇缝 + 鼻梁前缘**保护蒙版锁死 **100% 原始焦平面锐度**（保证正片灵魂焦点锐利通透），对头发中大束、手臂皮肤、黑裙布面与鞋面做极轻微的光学柔化（等效 `sigma ≈ 0.5–0.7px` 高斯/轻微景深匹配），把主体全局 `lapVar` 从刺眼的 `140+` 回落到与所在景深协调的 **`70–105`** 区间，立刻消灭“剪纸边缘刀切感”。

### 支柱 3｜双半径逆光包裹（Dual-Radius Backlit Light Wrap + Halation）
- 真实强背光绕过衣物与发丝时，既有贴边 **`6–12px` 的干净亮金窄边光**，也有 **`30–48px` 的低浓度大空气光晕**从亮背景轻轻吃进人物内缘（重点加在迎光侧 `left / top` 边缘，背光侧只留极弱漫射）。
- 仅用 `Screen`（低透明 `12%–26%`）或 `Linear Dodge (Add)` 配合低 `fillOpacity`（`15%–32%`）制作，防止白色硬滚边。

### 支柱 4｜Z-Depth 空气透视与聚光主次（Depth Haze + Spotlight Focus）
- 利用 Blender 导出的 16-bit `ZDepth` 深度图：在**主体后方（`Y > 3.5m`）到远景喷泉之间**按物理距离指数渐增叠加极薄一层**淡冷天蓝/珍珠白空气雾**（`Screen / Normal` 低不透明度），自然浮浅远景黑位、吞掉远处琐碎砖缝对比；
- 在背景四周边角做柔和小幅度压暗，并搭配白金芯丁达尔斜射光束引导视线聚焦主角脚下与上半身。

## 四、画发质感与环境光协同（藏色 × 成束 × 逆光游丝）

结合 [厚涂方法卡](painterly-methods.md)，换了环境光后头发必须跟着环境重塑，否则头顶还停留在棚拍感里：
1. **顺流向成束概括与写实保真优先**：按目标实际画风决策——写实/实拍正片走 `hair-comp --mode real-first` 完整保真原生 4K 高清发丝，只清理夹缝死白背景、外缘杂边与温和回收内侧逆光雾（禁止用 `<=1K` 超分厚涂发片或程序直线划痕硬替）；二次元厚涂如需延伸大发束，也必须用 `clamp` 压制超分油画脊线并使遮挡缘紧贴真实手臂零缺口。
2. **束间暗槽与冷环境“藏色”（`BV1hVgLe1EKG`）**：加深发束交叉压叠处的暗槽体积，并往暗侧与半透明阴影过渡区轻带入背景同步的冷薰衣草蓝，实现冷影暖光咬合。
3. **破除抠图硬边的光影协同**：外缘结合 `harmonize` 输出的双半径光学 `Light Wrap`（已带暗黑衣退让护栏）与少量与头发高频质感一致的飞丝细节，既打破机械抠图硬边，又不露胶丝或断头痕迹。

## 五、PhotoCraft 分层调色溶图标准配方 & 量化体检脚本

### 5.1 推荐图层接入位置
1. `01_BG_Clean` → 复制 `01_BG_DOF`（挂 Alpha `ZDepth` 通道做克制 `lensBlur`：`radius 5.5–7.0`, `threshold >= 245` 防高光白点）。
2. `02_Ground_Shadows` → 三层冷青灰阴影（`Contact` + `AO` + `Cast`，紧随洁净背景的真实暗亮比，**带斜坡透视防悬空脚跟**）。
3. `03_VFX_Behind_Subject` → `03a_Depth_Air_Haze`（Z 深度远景雾）→ `03b_Volumetric_GodRays`（白金微暖、`linearDodge fillOpacity 28%–35%`）→ `03c_Petals_Background`。
4. `04_Subject_Main` → `04a_Subject_Cutout`（已完成分级锐度与法式发束整理）→ 剪贴层组：`04b_BlackPoint_Match`、`04c_Directional_Relight_Shade`（压实背光臂与右半侧）、`04d_Dappled_Sun_Kiss`、`04e_Backlit_LightWrap`（双半径溢光）、`04f_Cool_Floor_Bounce`、`04f2_Subject_Clean_Match`（微校人物肤发清透度）→ **不剪贴**在组顶加 `04g_Hair_Backlit_Flyaways` + `04g2_PhotoCraft_Accent_Wisps`（`paint.stroke` 破抠图硬边）。
5. `05_VFX_Foreground_And_Optics` → `05b_Petals_Foreground`（动态模糊、严禁挡脸/鞋/裙心）→ `05c_Pollen` → `05d_FG_Framing_Vine` → `05e_Soft_Halation` → `05f_Global_Color_Grade` → `05g_Micro_CA` → 最顶层 `05h_Unified_Film_Grain`（50% 中灰 `softLight` + `1%–2%` 单色高斯颗粒）。

### 5.2 交付前量化色彩与锐度体检清单
每轮重大合成调色结束，除了用 `99_CHECK_LAYERS` 做黑白/色偏/饱和度诊断外，务必用 Python 核对以下硬指标：
- `shd_hue_deg` 落在 `195°–250°`（冷蓝紫阴影）或 `shd_sat <= 22%`；
- `hi_sat <= 9%`（高光无蜡黄溢出）；
- `sat_mean` 落在 `14%–26%`，`luma_mean` 落在 `128–152`（高透版）；
- 背光侧皮肤亮度 `<= 受光石板地亮度 - 18`；
- 主体 `lapVar` 与背景 `lapVar` 比值回落至合理光学景深差（眼部保持高锐、外缘与衣面柔合），皮肤 `Lab b*` 保持温和奶油区间（`7.5–13.0`）。

## 六、38 张商业 COS 成片实证基准与 `relight-sculpt` / `cinema-grade` 落地标准

通过抽样统计 38 张高质感电影感 COS 合成正片的 `CIE Lab` 与光影结构，确立以下强制标准：
1. **黑位与动态范围红线（拒当泛白灰雾图 + 实景前景框景）**：
   - 全片最暗 2% 黑位目标 **`p02_L <= 22`**（参考图高调实测可达 `8–18`），动态跨度 **`p98_L - p02_L >= 62`**（优秀电影级通常在 **`70–85`**），泛白高光区（`L* > 85`）严格控制在 **`<= 22%`**（越靠近 **`12%`** 越有电影通透质感）；
   - **禁止**对亮场背景全程叠加高浓度全屏灰白 `Screen` 雾气/泛光，也不得只靠微弱平面黑角蒙版交差：必须用 **`cinema-grade --mode bg-anchor`** 只保住光束与焦点亮区、主动压暗背光柱廊，同时配合 **`fg-vfx-3d`** 渲染大光圈真实前景暗框道具（如铁艺、花叶、暖金折光点）把人物物理夹入景深层次中。
2. **2.5D 物理体积重打光与因果光照联动（`relight-sculpt` + `fg-vfx-3d`，零人物 AI 重绘）**：
   - 使用 Apache-2.0 `Depth-Anything-V2-Small` 对人物前景做紧贴裁剪单目深度与表面法线估计，按场景主光方向导出 `Multiply` 体积暗部、`Screen` 迎光面提亮、`Screen` 菲涅耳轮廓包裹与 `Soft Light` 地面反光 4 张剪贴层；同步配合主拱门逆光轮廓光（`subject_arch_backrim_screen`）与贴身光带近距因果反射光（`vfx_wrap_causal_spill_screen`）；
   - 在保护眼神与内面通透感的同时压实背光侧颧骨/下颌/手臂/裙褶暗部，与场景光影真正长在同一盏灯下。
3. **PhotoCraft 原生电影调色收束（`cinema-grade --mode grade`）**：
   - 使用 `layer.newAdjustmentLayer.colorLookup`（`interpolation: "tetrahedral"` 加载 `resources/luts/*.cube` 33³ 标准电影 3D LUT）+ `filter.cameraRaw` 三轮校色 + `colorBalance` 统一把人物与背景阴影收入同组冷青/暖金电影色调；高光微光晕（`Screen`）必须**仅从锚定建筑亮部（`L > 0.88`）单独提取**，严禁把前景粒子雾斑喂进光晕层。

## 七、场馆去平光 × 多光源场景解析 × 特效因果局部重打光流程（De-Light × Multi-Light × VFX-Causal Relight）

当原本在漫展场馆平光/棚拍软箱下拍摄的人物放进夜间、霓虹都市、强火光或带有大面积发光特效的场景时，仅靠一层统一冷压暗仍会出现两大假象：**① 背光面肤色和黑衣残留原本场馆平光与天花板黄浊，像贴纸飘在夜景上；② 画面里的特效粒子/光环不会真实照亮人物邻近衣袖、发梢、下颌与周边建筑。** 基于 Nuke 2.5D 交互重打光机理与纯确定性物理，工作台建立三段标准链路（零人物 AI 重绘）：

1. **场馆去平光与暗衣净化（`relight-sculpt --delight-strength 0.65`）**：
   - 在 CIE Lab 空间按高频锁纹理分离出宽半径室内平光底频 `L_lo` 与真实细节高频 `L_hi`；只对背光面超出夜色基准的过亮平光 `max(L_lo - floor, 0)` 平滑压实，同时保持 `L_hi` 毛孔织纹 100% 完整；
   - 对 `--skin-mask` 施加热血红黄安全底线（`Lab b* >= 2.5`）防夜色压出灰青僵尸脸；对 `--garment-mask` 洗掉棚顶灯造成的 `b* > 0.4` 暖黄浊气，并平滑人脸区 2.5D 法线消除鼻梁侧陡坡脏线。
2. **背景多光源自动/手动解析（`relight-sculpt` Layer 5–7）**：
   - 自动扫描背景（排除主体掩码外）高亮度高彩度彩色聚光灯源（如霓虹灯牌、红伞灯笼、冷青招牌）生成多点 2.5D 点光源漫射与高光层，或由 `--accent-light "x,y,#RRGGBB,radius,strength"` 显式传入多光源；
   - 深色反光服饰通过亮度平滑斜坡区分漫反射暗面与镜面褶皱峰，仅让高光褶皱与外缘轮廓吃进彩色霓虹高光，再配 `07_dark_garment_neutral_color` 护住背光黑衣中性质感。
3. **2.5D 法线调制特效因果反光（`vfx-overlay --normal-map ... --fg-rgba ... --garment-mask ... --bg ...`）**：
   - 借鉴 VFX 交互打光（Nuke Relight / PointLight）原理，对去黑底后的特效能量场做近/中/远三尺度高斯滤波，并求中尺度光场 Sobel 梯度与主体 2.5D 法线点乘（`dot(N_xy, grad_E)`），同步导出三层非破坏光效：
     - `vfx_causal_broad_spill_screen.png`（`Screen`，Reinhard 滚降防过曝，剪贴于主体）；
     - `vfx_causal_hot_rim_add.png`（`Linear Dodge (Add)` 配 `fillOpacity ~44`，仅勾近距受光边缘与漆皮/丝绸光泽脊）；
     - `vfx_causal_env_spill_screen.png`（`Screen`，置于主体下方反馈照亮周边地面、栏杆与立柱）；
   - 同时由眼周面部守卫压住正脸高光溢出，保证妆容与眼神通透。
4. **防身体糊化红线（Anti-Body-Mush Guardrails）**：
   - 严禁在人体肌肤/肢体上**先重度 `Multiply` 压暗、再连叠多层宽半径模糊 `Screen` / `Add` 雾罩**（会把肢体微反差与肌肤真实质感洗成一片灰紫泥团）；定向主受光优先改用保反差的中性灰 **`Soft Light`**（`opacity ~0.62–0.68`），保留黑位与肌肤原生纹理；
   - `Depth-Anything-V2` 产生的 **Fresnel 边缘光必须严格用主体外轮廓距离场（`edge_dist`）门控在外边缘**，严禁因手臂/手掌/衣领的内部深度阶跃而在躯干或手指周围炸出一圈白雾晕；
   - 服装/皮肤语义掩码在切入重打光前必须先补齐内部孔洞，防止黑色反光服饰漏出“奶牛灰斑”；前景大光斑特效（`04c` 等）需剔除落在暗色皮革或肢体内部的低频雾团，让高光与深黑褶皱保持刀切层次。

> **开源选型边界说明**：调研对比过 `compphoto/Intrinsic`（高分本征反射/阴影分解）与 `GhostCai/PortraitRelighting`（Apache-2.0 NeRF 人像重打光），因两者均会重算或重绘原始人物皮肤纹理像素、违反本工作台 **Pure-PC 零人物 AI 重绘** 铁律，工作台保留 Apache-2.0 `Depth-Anything-V2-Small` 仅作 2.5D 法线提取，结合上述确定性数学重打光管线实现零损耗落地。
