# 人像与 COS 骨相液化实操指南（PhotoCraft 版）

结合龙吉《液化工具与修脸的五大原则》（`BV1GE411D7Nr`）与雷雨《瘦脸修容人像液化》（`BV1ta411J7cp`）的视觉与原理总结，作为进入自然美颜精修和厚涂前**必须最先执行的结构前置步骤**。

> **硬性顺序原则**：**骨相液化必须在高低频磨皮、斑点消除、精细蒙版与皮肤调色之前完成**；一旦液化完成并验收通过，必须**基于 `03_liquified.png` 重新生成 `face-parse`、`body-parse` 与 `matte` 蒙版**，禁止把液化前的旧蒙版直接套用在液化后的像素上。

---

## 1. 修脸审美与五大骨相原则（先准后瘦）

1. **中轴线校准**：`眉心 → 鼻梁 → 鼻头 → 人中 → 唇珠 → 下巴尖` 保持在符合当前歪头角度的自然中轴线上，先纠偏再修瘦。
2. **三庭五眼**：对照发际线—眉心（上庭）、眉心—鼻底（中庭）、鼻底—下巴尖（下庭）与五眼横向比例，仅纠镜头畸变引起的失衡，不硬改角色或真人原本韵味。
3. **鼻翼与内眼角对称对齐**：萌妹/二次元 COS 角色鼻翼总宽通常收敛至约等于或略大于两内眼角距离；严禁把鼻翼捏瘪成三角尖块或丢掉真实鼻孔透视。
4. **头包脸（高颅顶 + 颞部微扩）**：微提发顶轮廓与耳上颞侧蓬松度，柔和收窄颧弓最外缘突兀外凸，自然形成“头包脸”比例而非一味猛削下巴。
5. **下颌线保留骨相支撑**：顺着原本咬肌—下颌角—下巴曲线微收起伏、抹顺凹凸不平，**绝不削成尖锥网红脸**；肩颈斜方肌线条轻轻**向内、向下**压顺，锁骨保持平顺延伸。

---

## 2. 冻结保护与无畸变操作纪律

- **五官与背景硬线先冻结**：正式推动前，先调 `retouch-ai.py face-parse` 生成 `faces.json` 中的 `liquify_freeze_polygons`，在 `filter.liquify` 中以 `lassoMask`（`amount: 1`）冻结：
  - **双眼与眉弓**（防推高太阳穴时连带拉斜眼尾）
  - **鼻头与双侧鼻翼**
  - **嘴唇与唇角**
  - **贴近肩颈、发际、衣领的直线背景或道具边缘**（若在纯墙或木框前拍摄，先冻硬直线再推发丝/肩颈）
- **低压力渐变推揉（`pressure: 12~25` / `density: 35~50`）**：遵循教程示范的低压力微调原则，用大半径（略大于要调节的局部区块）短距小步推进；不在下颌尖、耳廓尖或手腕关节尖端做窄笔触猛拉。
- **使用智能对象留退路**：执行 `layer.smartObjects.convertToSmartObject` 后再跑 `filter.liquify`，方便后续微调或与未液化底图做半透明混合。

## 3. PhotoCraft 命令映射

```json
{
  "id": "filter.liquify",
  "params": {
    "meshSize": 2,
    "strokes": [
      { "tool": "lassoMask", "amount": 1, "points": [[x1, y1], [x2, y2], ...] },
      { "tool": "forwardWarp", "size": 140, "density": 40, "pressure": 18, "points": [[sx, sy], [ex, ey]] }
    ]
  }
}
```

## 4. 必做“照镜子”终检与翻车排查

每轮液化后，将底图与液化图做左右并排 + **水平翻转对照图**（`Original | Liquified | Horizontal Flip`），用 `inspect` 或看图逐项核对：

| 翻车表现 | 排查原因与纠偏动作 |
| --- | --- |
| 正常看没察觉，水平翻转后立刻觉得嘴歪/下巴斜 | 五官中心未对准中轴或左右颧骨/下颌推量失衡；回退并对照中轴线对称微调 |
| 眼角被拉吊、下唇被拖糊 | `lassoMask` 范围过小或笔刷半径压进冻结边界 |
| 后景门框/墙角/耳饰垂链变S形弯曲 | 未冻结人物外缘邻近直线，或小笔刷在轮廓边缘反复刮擦 |
| 人像失去个人特征变成僵硬蛇精脸 | 推量过大且把下颌角转折彻底抹掉；保留下颌折角仅收顺外廓起伏 |
