# COS 与人像精修技术与避坑细则（PhotoCraft 版）

汇集实机踩坑总结的硬边界与细节核查要点。执行特定环节时按需查阅，不把工具机制当成“每张图必跑”。

---

## 1. 显影、超分与色彩管理

- **核查真实文件头与扩展名**：部分平台或超分工具导出的 `.png` 实际可能是 JPEG/JFIF（无真实无损通道与透明背景）。接图先用 `scripts/inspect-image.mjs inspect` 核对 `format` 与 `extension_matches`。
- **超分输入边界**：扩大像素或转为 16 位**不能**恢复原始拍摄丢失的传感器细节；低分辨率原片或裁切素材需放大时，可用 `retouch-ai.py upscale --scale 2`（`Real-ESRGAN-ncnn-vulkan`）处理，之后**严禁默认再叠锐化**，先看 1:1 基线是否存在振铃、白边或塑料平滑感。
- **Camera Raw 滤镜局部与整体分工**：`filter.cameraRaw` 适合先稳住主光曝光、白平衡与高光/阴影，支持参数化局部曲线、HSL、色调分离与校准；但混合光场景（如正面直闪 + 现场紫光/青光）不要用全局色温滑杆把氛围轮廓光一并洗成中性灰，应配合图层蒙版分区控制。
- **Assign vs Convert Profile**：无嵌入 ICC 表示“缺少颜色解释标签”，不能直接猜成原相机色空间。`edit.assignProfile` 只改解释不改数值；发往网页/手机前应使用 `edit.convertToProfile`（如转 `srgb`）并保留外观，避免跨设备偏色。

## 2. 瑕疵清理、高低频与跨材质修复

- **高低频（频率分离）验证纪律**：
  1. 用 `image.applyImage` + `filter.blur.gaussianBlur` + `linearLight` 搭建高低频结构后，**在未做任何修改前先开关整组对比原基线**，确认像素重构一致（无明显色阶/亮度漂移）才继续。
  2. 高低频只是职责分工（低频管色块明暗，高频管皮肤/织物纹理），建好组不等于完成磨皮或去皱。
  3. **低频修复严禁从含高频的可见合成层取样**：若在低频层做克隆/修补，必须指定低频来源层（例如 `paint.cloneStamp` 设 `sampleLayer: "current"` 在低频层内取样），否则会把高频纹理二次叠进低频并放回高频下方造成双重重影。
- **内容识别与跨材质陷阱**：
  - `edit.contentAwareFill` 与 `paint.remove` 只适合周围纹理单纯的小范围杂物。
  - **靠近眼线、睫毛、金属饰品边、发丝或跨越两种材质的胶带**（或大块漫展路人）时，内容识别极易拉入邻近异色像素或生成重复伪影（例如把红衣纹理拖进青绿假发）。可先用 `retouch-ai.py inpaint --patch-only` 生成透明局部补丁并用 `doc_place` 非破坏置入，或改用指定方向与源点的 `paint.cloneStamp` / `paint.healingBrush` / `paint.patch` 逐段处理，并做 1:1 裁切验收。
  - **换背景抠图前的 `LaMa` 糊斑陷阱**：严禁在 `BiRefNet` 抠图前用 `LaMa` 大面积抹除主体轮廓附近的衣物飘带、系带或发丝交界杂物——`LaMa` 会用原背景色将其涂成大块灰白糊斑，后续抠图会把糊斑当实心前景整体带入新背景。正确做法是保留原物进抠图，或换背景后再在独立非破坏层局部清理，并对照最原始输入图核验。

## 3. 主体抠图、局部修补与边缘细化

- **初始主体选区的真实定位**：`select.subject` 只产生初始选区/蒙版，不等于发丝级精抠；复杂发丝与薄纱可先用 `retouch-ai.py matte`（`PP-Matting V2`）生成软边缘 Alpha，或再用 `body-parse --refine-with-matte` 拆出头发/皮肤/服饰蒙版。必须用纯深色底与纯浅色底分别检查：假发细丝、飘带、半透明饰品、以及**常被自动算法误当成背景抠掉的暗部皮肤与肢体间空隙**。
- **高质量发丝抠图边界重建铁律（`cutout-refine`）**：严禁把全身高分辨率主图（如 4K–5K）直接粗略缩放到 `1024px` 推理后再拉回 4K 贴合，否则极易导致碎发丝被啃出“断层锯齿”且边缘残留深棕/洋红/灰背景溢色。应调用 `retouch-ai.py cutout-refine`：先对主体边界做高分分块重抠再配合连续色彩线局部 `F/B` 光学前景解算（近邻真实发色去溢色），使半透明细丝顺滑连贯。
- **已有蒙版的局部修补**：发现漏选皮肤或边缘多余背景时，直接在目标图层蒙版上用 `paint.stroke` 设 `target: "mask"`（白补回 / 黑隐藏）局部修补即可；不要轻率用整图重做覆盖掉此前已经精细修好的局部。
- **颜色净化与纯半透羽化去白边铁律**：`select.refineEdge` 支持 `radius`、`smartRadius`、`smooth`、`feather`、`contrast`、`shiftEdge`、`decontaminate`（颜色净化）与 `refineStrokes`。注意：
  - 收缩边缘（负 `shiftEdge`）不是除色的等价物，收太猛会把细发丝削成硬壳。
  - **纯半透羽化去溢色**：自动化或手修对深色衣物/鞋袜去抠图白边时，**仅限修改半透明羽化环（`0.02 < alpha < 0.88` 及其外围 1px），严禁把深像素涂过实心边缘或取远距深黑填进亮鞋底边**，避免出现硬锯齿黑描边；同时保留现场有益的真实轮廓色光。
- **AI 语义分割的局部色度防误判规则**：`SegFormer` 对服饰与阴影区偶发两组误判必须做像素级物理护栏：① 强光发白的膝盖易被并入 `mask_pants`，衣物精修与 `skin-unify` 扩展必须对高亮暖肤（`L* > 50 & a* > 4.2`）放行；② 外侧过曝漂白发丝低彩度高亮段与白飘带/蝴蝶结相似，跳过白饰品时必须联合 `hair_m` 与 `b*` 暖黄分量判断，绝不能连漂白假发一起跳过。
- **蒙版连续性、防破洞与零硬切红线**：修补服饰与皮肤蒙版时**严禁使用硬布尔矩形坐标切边（如 `x >= const`）或硬布尔 `Lab` 色度阶跃阈值（`np.where(b < thresh, b + delta)`）**，一切区域交界与色调护色必须采用平滑坡道（`_smoothstep` / 连续 Ramp）；填充深色高光服饰内部的 `SegFormer` 蜂窝破洞前必须先保护真实暗侧手臂/躯干皮肤免被反吞，并通过 `retouch-ai.py mask-audit --garment-mask ... --subject-alpha ... --skin-mask ...` 核验零溢出主 Alpha 与零未认领内洞。

## 4. 液化与结构变形

- **非破坏智能滤镜流程**：需要微调脸型、体态或服饰轮廓时，优先复制人物工作层并执行 `layer.smartObjects.convertToSmartObject`，再在其上运行 `filter.liquify`，使液化成为可回改的智能滤镜；勿直接覆盖唯一原像素层。
- **冻结锚点与防拉扯**：
  - 在 `filter.liquify` 中可按笔画顺序组合 `lassoMask` / `freeze` 保护不希望歪斜的锚点（五官相对轴线可从 `retouch-ai.py face-parse` 生成的 `faces.json` 读取 `liquify_freeze_polygons` 传入 `lassoMask`、头颈连接、关节、服装硬边、假发发际线、邻近直线道具）。
  - 使用低密度/低压力短笔划单向微调；局部过度推拉时用 `reconstruct` 工具局部回退，而不是继续往反方向硬推。
  - 变形后必须在整图与 1:1 视图检查背景直线是否出现波浪、衣纹和缝线是否突然变宽或断裂。
- **多点网格形变**：大范围姿态或飘带微调可使用 `edit.puppetWarp`（固定关节锚点后移动端点）或 `edit.transform.warp`，局部纹理位移可用 `filter.distort.displace`。

## 5. 合成整合、景深、接触影与输出锐化

- **先对齐物理关系，再调颜色**：`doc_place` 置入智能对象后，先匹配机位视角、地平线、人物尺度、主光方向与黑位，再借助调整层与蒙版做局部色温与亮暗融合。没有接触面的半身肖像不要凭空硬画落地阴影。
- **接触阴影写法**：接触影是贴近支撑点最深硬、离开接触处随主光方向逐渐扩散变软的独立影子层，需配合局部蒙版与透明度，不要靠整圈均等暗边描轮廓。
- **全黑衣遮罩透传与反弹光屏蔽**：只要经过 `garment-retouch` 兜底修复的残留鞋靴（`residual_dark_garment`），必须通过 `--out-dark-mask` 把完整黑衣遮罩透传给 `harmonize --garment-dark-mask` 与环境反弹光计算；同时对 `Screen` 类型的墙面/地面反弹光主动屏蔽已压暗的下肢膝盖阴影区，防止把裙下物理遮挡重新冲亮。
- **黑底 AI 特效主次守恒与防过曝规则（`vfx-overlay`）**：人物与核心场景陪体永远是第一焦点。黑底特效去底切忌同时把 `auto-split` 前景/后景叠满后再追加高不透明度 `Linear Dodge (Add)` 或把大片尘雾喂进全局光晕层；启用 `--density-gamma` 与 `--haze-suppress` 保持严格能量守恒（`a_behind + a_front <= alpha`），仅以稀疏星点衬托氛围。
- **Blender 透明世界下前景玻璃散景防黑心规则**：在 `film_transparent = True` 下用纯折射玻璃材质渲染前景近焦挂坠/水珠时，折射空背景容易形成诡异的“深黑空心圆环”。应改为 `LayerWeight` 驱动的 `Transparent + 暖色微发光` 混合着色器，让景外水晶呈现柔和通透的暖金色电影散景光斑。
- **高调强侧光服饰的 `mask-audit` 审计边界**：做 4:1 强侧光/逆光重打光后，浅色/高调服饰（如亮乳白蕾丝、`p50_luma >= 120`）在下颌投影与迎光上胸之间天然存在 `40–52` 亮度落差；审计已自动区分深色匀色衣（严格 `<= 38` 防偏棕断缝）与高调重打光服饰（`58` 硬限 + `38..58` 提示目视核查 `audit_garment_overlay.png`），防止误杀真实光影过渡。
- **输出锐化控制（`retouch-ai.py output-sharpen` · 严禁对成片整图跑 AI 超分）**：最终导出前的输出锐化优先使用 `output-sharpen`（线性亮度 Richardson-Lucy 反卷积 + 非对称正增量钳制 + 扣像轮廓防振铃护栏 + 四级语义焦点权重蒙版，以可开关智能对象 `Linear Light` / `Luminosity` 放在顶层胶片颗粒正下方），或使用独立合成副本执行小半径 `unsharpMask`/`smartSharpen`；重点提眼瞳、睫毛、唇缘、发丝与服化道织纹，严格避开光滑肌肤、扣像外缘与远景散景。**红线：严禁把已经合成光影、特效和颗粒的终稿整图丢进一键 AI 画质增强/超分器里重新绘制，极易篡改真人长相、勾出硬白边并把粒子与肤质糊成塑料蜡像。**需要在目标尺寸与 `1:1` 放大同步核查零白边、零皮肤噪点。

## 6. 教程转可复用经验与工程边界

- 收录外部方法或实验结论时，明确区分来源访问层级（正文/自动转写/仅标题索引），不把没看全的视频或教程示范效果图直接当成“本机已验证”。
- 保留失败实验及其触发原因（如某处跨材质内容识别失败、某个粗略椭圆误涂眼白），避免重复踩坑；**不要把个人照片路径或单张图的硬编码像素坐标写进通用技能规则里**。
