# 场照与正片工作流程

按当前任务区分拍摄场景与交付目标。以下是观察与操作的选择依据，不是每张图都要运行的固定工序，也不是自动效果承诺。

## 1. 场照与正片的目标区分

场照也能精修，正片也能保持自然、保留原景，重点在于目标而非简单按修图强度划线：

| 判断项 | 场照（`field`）常见目标 | 正片（`formal`）常见目标 |
| --- | --- | --- |
| 拍摄条件 | 漫展现场，常见杂光、路人、杂乱背景 | 围绕角色安排的棚拍、外景或主题拍摄 |
| 后期重点 | 把人与妆造表现清楚，清理干扰，稳定返图质量 | 建立角色气氛、叙事、画面秩序与组图连贯性 |
| 人物处理 | 按需要清理明显瑕疵、穿帮与局部偏色 | 按角色及参考细化脸部、假发、服装、道具 |
| 背景处理 | 原场景清理、压低干扰，必要时局部修补 | 可保留、扩展或重构场景，服务创作目标 |
| 光色处理 | 校正失控偏色，突出主体，协调同组曝光/色温 | 进一步匹配环境色、明暗结构、气氛与视觉重心 |
| 特效 | 有明确表达作用才添加 | 仍需服务角色及场景，不作为必备条件 |

## 2. 共用的判断与处理顺序

1. **先定画面意图，再查像素基础**：核对角色参考、妆造意图、需保留的个人特征与目标画风（自然轻修 / 质感精修 / 二次元厚涂）。区分可修偏色穿帮与真实缺失细节（虚焦/过曝死白不能伪造成“真实细节恢复”）。
2. **先校正，后风格化**：先处理曝光、明显白平衡与局部杂光，再决定灰调、暗调、冷暖或厚涂。人物、皮肤、假发与服装不要共用一个粗糙的全局调整；混合光场景（如直闪 + 现场紫/青光）不可全图硬去某色。
3. **人物分问题处理**：
   - **皮肤**：先清临时点瑕疵，再按画风决定是否均匀局部颜色/明暗或做高低频。不要用全脸模糊代替质感判断。
   - **妆面**：眼线、眼影、卧蚕、角色纹样、雀斑或战损妆属于主动设计，不可当污点消除；磨皮/柔化时须保护眼唇与睫毛边缘。
   - **胶带与假耳**：先修接缝，再单独匹配局部明度与色相，检查连接处是否仍属于同一块皮肤的受光逻辑。
   - **假发**：区分乱飞杂丝与角色必需的外轮廓；清理发网/碎丝时保留毛流、分束与暗侧，避免涂成硬壳或头盔。
   - **形体**：先分辨是镜头透视、衣料堆叠还是需要微调的形体。采用液化时须用冻结蒙版保护固定锚点，并复核邻近直线、道具与衣纹是否拉弯。
   - **衣装与道具**：去灰尘与非结构褶皱时保留布料、蕾丝、金属、皮革的材质区分，不抹平受力褶与结构线。
4. **先存可编辑工程，再输出交付副本**：先保存带完整图层的 `.pcraft` 或 `.psd`，再按发布要求转换（而非仅仅重新指定）色彩配置文件输出 JPEG/PNG，并另路径导出以保护原图。

## 3. `field`：场照返图 7 步流程

1. **按光线分组并选片**：优先用 **LightCraft**（`import` / `query_photos` / `select_photos`）挑表情、焦点、动作与妆造状态正常的照片，同光线建立一张基准。
2. **基础校正**：在 LightCraft 中稳定曝光、白平衡与色彩分级并同步给同光线组；混合光采用局部蒙版修正，保留现场有益色光。
3. **主体与背景分开调整**：导出到 PhotoCraft 后，协调脸、颈、手与服装关系（可用 `retouch-ai.py body-parse` + `face-parse` 生成皮肤/服饰/头发蒙版，并跑 `qa --skin-mask` 检查肤色偏移）；适当压低背景亮度或杂色突出人物。
4. **人物与妆造清理**：优先处理胶带、发网、明显点瑕疵、乱飞杂丝与衣装灰尘。
5. **背景干扰清理**：小纹理用 `edit.contentAwareFill` / `paint.cloneStamp` / `paint.patch`；大面积路人或跨材质遮挡用 `retouch-ai.py inpaint --patch-only` 生成透明补丁层置入，逐处 1:1 检查是否出现重复图案或断线。
6. **轻量光色塑造**：仅对需要区域小幅强化主次，保持皮肤、布料与金属的质感差；无需修的区域不强加高低频或减淡加深。
7. **同组统一与逐张核对**：基准方向同步到同光线照片，但构图/位置/曝光有变时必须重新定位局部蒙版，不可机械套用坐标或曲线；收尾可用 `retouch-ai.py compare` 做全图 + 1:1 局部对比验收。

- **场照停止标准**：人物与妆造清晰、明显干扰已清理、肤色与衣料未遭过度滤镜破坏、同组观看无意外跳色，即可停止。

## 4. `formal`：角色正片 8 步流程（严格两阶段门禁）

1. **建立视觉目标**：对照角色与风格参考，确定主光方向、明暗主次、主色与视觉焦点；若需转厚涂方向，先确定是否允许明显塑形与重绘。
2. **阶段一 · 自然美颜底图精修与服饰/下肢分频预处理（硬门禁，必须先出图并独立 `1:1` 验收）**：按 [液化指南](liquify-guide.md) 与 [自然奶油肌精修指南](natural-beauty-guide.md) 先完成暖润显影 → 骨相液化（照镜子检查）→ 液化后重跑蒙版 → 瑕疵/超分黑线及**跨眼眶杂乱发丝清理**（**严禁在抠图前用 `LaMa` 抹除衣物边缘飘带或发体夹缝杂物，防糊斑被锁进前景抠图**）→ 额头校准高低频与 D&B → 3 步奶油瓷白肌统一全身皮肤 → 自然眼唇与 **`garment-retouch --out-dark-mask`**（按 [服饰精修指南](garment-retouch-guide.md) 仅在 CIE Lab 明度 `L*` 去雾并锁死织纹、做半透明羽化去白边，同时导出含鞋袜与兜底深色鞋的完整深色服装罩）+ **`skin-unify`**（对齐手臂晴光肤色、清腿缘白边并叠黑裙/交叠腿遮挡影）→ 产出独立可交付的 `01_beauty_base.png` + `.pcraft`。
3. **透视、光向与高分辨率场景底片准备（`linear_ratio >= 0.6`）**：严格按 [合成与溶图指南](compositing-guide.md) 先核对视平线、焦段畸变与主光方向；严禁把低清 `<=1K` 生图盲目 `realesrgan 4x` 当成 4K 背景使用，必须走 `tile-split` → 分块高清精绘 → `tile-stitch`（低频锁光影）跨过 `0.6` 原生分辨率门禁。
4. **建立蒙版、按画风合发/画发与 PIH 人景溶图**：以 `retouch-ai.py matte --model birefnet-lite` + 默认 `SegFormer-B2 Clothes` 18 类 `body-parse` 精准拆分头发与服装/皮肤，按实际画风调用 `hair-comp`（实拍风默认 `real-first --groom` 保留原生 4K 连续发丝、顺发流轻理顺炸毛并回暖漂白发白斑，同时零间隙避让手臂；需要飘逸毛流感时按 [分层画发丝指南](hair-painting-guide.md) 运行 `retouch-ai.py hair-paint` 输出**主体后景层 `02b_HAIR_PAINT_BEHIND_4K` + 主体前景层 `03b_HAIR_PAINT_FRONT_4K`** 的极细单丝束可开关图层组），随后执行 **`retouch-ai.py harmonize --garment-dark-mask <out-dark-mask>`（PhotoBlaze-PIH ONNX CUDA + 完整黑衣鞋袜防回灰保护 + 双半径 Light Wrap + 颗粒匹配）** 输出非破坏图层。
5. **三要素复核与物理光影补全**：在顶部建临时 `CHECK LAYERS` 诊断组，按主光方向补三层阴影（`multiply` 接触影 → AO → `fieldBlur` 近实远虚方向影）、反曲线扫受光面与局部地面反光（**环境 `Screen` 反弹光须排除已压暗的下肢膝盖阴影区**）；仅在需要二次元厚涂时才按 [厚涂方法卡](painterly-methods.md) 整合。
6. **空间景深、前后遮挡特效与溢光**：使用 `lensBlur`/`tiltShift` 对齐前中后景物理景深与空气雾；发光/水雾/粒子分“主体后/主体前”两层穿插，用 `blendingOptions.fillOpacity` 控制 `linearDodge` 光晕不过曝，并在手/衣/脸补足邻近溢光染色。
7. **胶水收束、全项掩码体检与独立 `1:1` 审图验收**：关闭 `CHECK LAYERS` 诊断组，加统一传感器颗粒层；导出前先跑 **`retouch-ai.py mask-audit`**（零破洞、零半透明残影、遮挡不断发、黑衣不偏棕、织纹保留、人景溶合度、原生分辨率门禁），并确认由视觉模型**亲眼审阅**全部热点与 `<=512px` 独立 `1:1` 切片（未看图仅算 `NUMERIC_PASS_VISUAL_UNVERIFIED`，严禁冒称最终通过），最后转 sRGB 保存终稿 `.pcraft` / `.psd` / `.png`。

## 5. 常见失败与排查表

| 失败现象 | 常见原因与排查方向 |
| --- | --- |
| 人脸像蜡或塑料 | 模糊/涂抹范围过大，纹理与骨相转折一起抹掉；回退并缩小范围，避开眼唇、鼻翼与下颌线。 |
| 脸和手像两个人的肤色 | 面部单独提亮或去色过度；连同颈、耳、手一起看受光协调，不强求 RGB 数值完全相等。 |
| 假发出现硬壳感 | 去杂丝过猛、蒙版边缘收缩过狠或过度平滑；对照原造型保留发束高低起伏与少量飞丝。 |
| 人物像贴纸贴在背景上 | 缺少接触阴影、光向或黑位不匹配、边缘留有硬白/紫边、或未同步景深与颗粒度。 |
| 背景清理留下重复图案 | 仿制或内容识别取样循环；改用多点采样方向性修复，并复查连续线条。 |
| 布料与金属失去质感 | 对非皮肤区域误跑高强度磨皮、表面模糊或降噪；按材质分开建立图层或蒙版控制。 |
| 踢出的鞋靴/黑袜带白边或溶图后发灰 | 未兜底 `SegFormer` 漏检鞋区，或去白边扩进实心内部画出黑描边，亦或溶图时未传入含鞋袜的 `--garment-dark-mask`；用 `garment-retouch --out-dark-mask` 仅清 `alpha < 0.88` 羽化边并透传给 `harmonize`。 |
| 下肢膝盖泛白无血色且和黑裙脱节 | 强逆光冲褪膝盖饱和度、`SegFormer` `mask_legs` 漏掉大腿上段或 `mask_pants` 误吞膝缘，且缺裙/交叠腿遮挡影；用 `skin-unify` 对齐手臂肤色、清左缘白边并补遮挡影，同时关闭下肢区的墙面 `Screen` 提亮。 |
| 手绘飘发像扁平色带、铁丝线或扫过眼颊 | 多簇笔尖在小间距下熔成平带、弧向脱离原发下落重力、未按起笔局部自吸发色或人脸避让过小；改用 `hair_03_single_strand` 极细聚簇单丝束 + 局部自吸混色 + 扩张 `face_guard`，并拆成主体后景/前景双组。 |
| 主体轮廓旁出现大片灰白糊斑 | 在 `BiRefNet` 抠图前用 `LaMa` 抹除了飘带或发体夹缝杂物；改用原图直抠或在换背景后于独立层清理，并与原片对照核验。 |
| 加了特效仍显空洞 | 特效缺乏明确光源、空间遮挡与邻近受光反射；回到主光与主体关系重整明暗。 |
| 发到手机/网页后偏色 | 未正确从工作色域转换到 sRGB 并嵌入配置，或仅用了“指定配置文件”。 |

## 6. 交付与状态表述纪律

- 仅当引擎确认保存成功且重开核对无误后，才报告交付文件已完成。
- 明确区分阶段状态：“已建图层/结构准备” ≠ “已实际绘制/修补” ≠ “已通过 1:1 细节与视觉验收”。
- 导出失败或发现缺陷时先保留当前可编辑工程文件或回退到稳定快照，禁止丢弃唯一工作成果。
